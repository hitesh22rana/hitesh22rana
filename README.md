# Hitesh Rana

I'm a backend engineer at Mercari. My public projects are mostly in Go and focus on scheduling, messaging, and making failure visible and recoverable.

## Selected work

- [Chronoverse](https://github.com/hitesh22rana/chronoverse) is a self-hosted job scheduler and orchestrator. It uses durable job leases, idempotency keys, a transactional outbox, and searchable execution logs.
- [jsonlogic2sql](https://github.com/hitesh22rana/jsonlogic2sql) translates JSON Logic into parameterized SQL across multiple dialects, with schema validation and custom operators.
- [MQ](https://github.com/hitesh22rana/mq) is a pull-based message broker built with Go and gRPC, with batched reads and write-ahead logging.
- [SoundScripter](https://github.com/hitesh22rana/SoundScripter) is an asynchronous transcription service using RabbitMQ, Celery, Redis pub/sub, and Server-Sent Events for live updates.
